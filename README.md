# QuizPet — GitHub Pages 버전

301문항의 전산직 자체 제작 연습문제, 펫 성장, 중복 없는 풀이 수, 오답노트.
HTML/CSS/JavaScript만으로 동작하며 서버·API 키·로그인이 필요하지 않습니다.

## 저장 방식

풀이 기록은 현재 사이트 경로에 해당하는 브라우저 localStorage에 저장합니다.
문제와 앱 코드는 공개됩니다. 학습 기록은 서버로 전송하지 않습니다.
PC·휴대폰·다른 브라우저 사이에 자동 동기화되지 않습니다.
브라우저 데이터 삭제에 대비해 화면 아래에서 기록 백업을 내려받으세요.
백업 파일은 같은 화면에서 합쳐 가져올 수 있고, 같은 기록은 중복으로 가져오지 않습니다.
개인 백업 JSON은 GitHub 저장소에 올리지 마세요.

## 배포

1. GitHub에 새 공개 저장소 `quizpet`을 만듭니다.
2. 이 폴더의 파일을 저장소 최상위에 올립니다. index.html이 최상위에 있어야 합니다.
3. Settings → Pages → Deploy from a branch → main / (root) → Save.
4. GitHub가 배포 완료 후 표시한 주소를 휴대폰에서 엽니다.

모든 문제의 출처는 AI 제작 · ChatGPT이며 실제 기출문제 원문이 아닙니다.
